# 🌊 Flood Prediction System

## 🚀 Overview
The Flood Prediction System is a full-stack web application that predicts flood risks using environmental and rainfall data. It provides insights such as flood probability, severity levels, and affected areas to help in early warning and decision-making.

---

## 💡 Features
- 📍 Location-based flood prediction  
- 🌊 Lake monitoring system  
- ⚠️ Flood severity classification (Low, Moderate, High, Severe)  
- 📊 Displays real-time flood prediction data  
- 🔍 Simple and user-friendly interface  

---

## 🛠 Tech Stack
- **Frontend:** React.js, HTML, CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MySQL  
- **Tools:** Git, REST APIs
